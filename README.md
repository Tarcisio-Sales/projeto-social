## Emulador CHIP-8

O diretório [`chip8/`](chip8/) traz um emulador completo do CHIP-8 escrito em
C99, com núcleo sem dependências, frontends de terminal e SDL2, desmontador,
suíte de testes e documentação em português.

```bash
cd chip8 && make && make run
```

Veja [`chip8/README.md`](chip8/README.md) para os detalhes.
